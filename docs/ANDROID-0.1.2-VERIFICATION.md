# 小米实机更新记录 · Android 0.1.2

2026-10-18，通过 USB 连接的实际设备为 Xiaomi 18 Pro（M610BB），Android 17 / API 37。应用从 0.1.0 覆盖更新，包名保持 `dev.mealtrace.app`，使用同一签名，未卸载或清除应用数据。iPhone 仍为 0.1.1；本次 Android 修订与其对齐扩库、搜索和自定义功能，并修复 Android 专有读取问题。

## 更新内容

- 共用完整 7,793 条 USDA SR Legacy 食物数据，113 条常用中文与别名。
- 分类、中文别名和英文搜索，支持选择完整英文原名目录。
- 个人自定义食物，按每100克填写能量和三大营养素，支持 kJ/kcal 换算、保存复用与 JSON 导出。
- 修复旧版通用读取器的 2 MB 上限阻止扩展食物表加载的问题：仅食物目录显式采用 8 MB 有界读取；其他小型资源仍沿用原限制。
- 原有离线模型、自动发现、照片权限、通知权限和个人设置保留。自动发现开关最终核对为开启；周期与内容触发任务均仍在系统调度队列。

## 实机检查

1. **23 项食物库检查通过**：完整数据与中文条目数量、别名、柑橘区分、蛋类烹调状态、奶脂区分、未知食物、分类与完整英文搜索、自定义保存重载和营养计算、来源标注、无效营养素/重复名称/非有限能量拦截、自定义 JSON 导出、既有模型就绪、个人自定义表及个人设置不变。
2. **7 项真实界面检查通过**：完整目录开关、自定义入口、水果分类、在搜索框输入“车厘子”后显示“樱桃”、打开自定义编辑及保存按钮、每100克单位说明。界面检查没有保存任何餐食或个人自定义项。
3. **17 项原有流程检查通过**：份量及用油计算、估算范围、未知/异常份量、实际食用比例、清理候选与收藏保护、导出不包含原图 URI、模型完整 SHA-256、候选筛选、普通应用 UID 内真实模型推理与解析等。
4. 公开 Nutrition5k 样图的真实模型调用耗时 **26.17895 秒**，运行在普通应用 UID 10341，CPU 路径。仅一次样图结果，不代表稳定速度；输出依然含重复食材与猜测的用油，不能据此声称热量准确。
5. **16 项 JVM 单元测试通过**：13 项原营养规则与3项读取边界/真实扩展目录回归检查。Release 构建与 lint 通过。

自定义验证在独立测试偏好文件中保存，随后删除该测试文件；没有向用户的个人食物表写入测试项。原有流程仅使用公开样图、自有临时相册图片和 2001 年的临时记录，验证结束后清理这些自建数据。没有读取私人照片用于模型测试，也没有执行用户相册清理。

## 范围与限制

本次已在小米验证新增选择界面、别名、个人食物持久化和本地推理；未进行多日锁屏、重启及耗电测试，未重新测试全部相册来源或月底实际删除。Android 和 iOS 受各自系统后台调度限制，不能承诺拍照后立即识别。模型估算仍须用户核对。

Debug 专用验证模式：

```sh
adb shell am instrument -w -e mode catalog dev.mealtrace.app/.Verification
adb shell am instrument -w -e mode catalog-ui dev.mealtrace.app/.Verification
adb shell am instrument -w dev.mealtrace.app/.Verification
```

Debug 验证代码和公开样图不包含在最终安装的 Release APK 中。原始验证 JSON、APK 和源码快照保存在本次交付目录。
